# 大土工作台

前后端分离的工作台。前端使用 Vue 3 + Vue Router 单页多路由布局，公共侧边栏、风险提醒、接口封装和富文本编辑器组件复用；后端使用 Python 标准库 + SQLite 提供轻量 API 和登录鉴权。

## 模块

- 今天待办：标题、富文本内容、优先级、截止日期、项目/团队目标关联、完成勾选、卡住标记、一键顺延、逾期自动迁移。
- 团队建设：月度/季度目标、行动计划、每周完成记录、卡点记录、人员盘点。
- 项目管理：项目信息维护、状态跟踪、任务分解、项目完成进度。
- 每周复盘：本周完成数量、优先级分布、项目精力分布、卡点汇总。
- 灵感速记：随手记录、标签管理、按标签筛选。

## 本地启动

```powershell
python backend/server.py --host 127.0.0.1 --port 8800
```

默认访问 `http://127.0.0.1:8800`，首次启动会初始化管理员账号。生产环境请通过环境变量覆盖：

```bash
DATU_ADMIN_USER=ops
DATU_ADMIN_PASSWORD=strong-password
DATU_DB=/data/datu/datu.db
```
