# 大土工作台

前后端分离的多页工作台。前端使用 Vue 3 与独立页面组件，公共布局、接口封装和富文本编辑器组件复用；后端使用 Python 标准库 + SQLite。

## 模块

- 今天待办：标题、富文本内容、优先级、截止日期、分类、完成勾选、卡住标记、一键顺延、逾期自动迁移。
- 工作分类：名称、说明、状态、任务关联与完成进度。
- 任务目标：分类下建目标，目标下分解子任务，并展示完成报表。
- 每周复盘：完成数量、优先级分布、项目精力分布、卡点汇总。
- 灵感速记：标签记录与标签筛选。

## 本地启动

```powershell
python backend/server.py --host 127.0.0.1 --port 8800
```

默认访问 `http://127.0.0.1:8800`，首次启动会初始化管理员账号。生产环境请通过环境变量覆盖：

```bash
DATU_ADMIN_USER=ops
DATU_ADMIN_PASSWORD=strong-password
DATU_DB=/data/datu/datu.db
```
